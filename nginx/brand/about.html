OMNIAPI / ABOUT

一个接口，多家大模型。

一个 Key、一个兼容 OpenAI 的地址，即可调用 Claude、GPT、Gemini、Grok、DeepSeek、GLM 等 29 个模型。按 token 公开计价，1 元起充。

为什么用 OmniAPI

  • 一个 Key 通六家。不用在六个平台分别注册、分别充值、分别对账；换模型只改请求里的 model 字段。
  • 接入几乎零成本。兼容 OpenAI 接口，改 base_url 即可，原有代码不用重写；同时支持 Claude 原生协议与 Responses 协议。
  • 计价规则公开。每个模型的输入/输出单价在价格页可查，按实际 token 用量扣费，不按次数收费，没有套餐外的最低消费。
  • 汇率固定，不玩浮动。人民币按 ¥6.7489 = US$1 折算额度，不随汇率波动——不会今天一个价明天一个价。
  • 额度是你自己的。不每日重置；手动续购，不自动续费，不会在你不注意的时候扣款。
  • 人工核验充值。扫码付款后由人工核对到账再加额度，不做伪装成"自动到账"的扣款。

接入信息

Base URLhttps://omniapi.biz/v1
鉴权Authorization: Bearer <你的令牌>
兼容协议OpenAI 兼容；Claude 原生 /v1/messages；/v1/responses
可用端点/v1/chat/completions、/v1/messages、/v1/responses、/v1/models

以上三种协议均已实测可用。任何支持自定义 OpenAI 兼容地址的客户端（ChatBox、Cherry Studio、NextChat、LobeChat 等）填上地址与令牌即可使用。

如何开始

  1. 注册账号，在控制台创建一个令牌（请勿把令牌或密码发给任何人）。
  2. 充值：打开账户充值，扫码付款后点「我已付款」提交申请，最低 1 元；也可以直接选套餐。
  3. 经营者在收款渠道核对到账后，额度直接计入你的账户，刷新钱包页即可看到。
  4. 把 Base URL 与令牌填进你的客户端或代码，选择模型开始调用。

我们不说的话

  • 不说"无限量""不限速"——额度按 token 真实扣除，是有限的。
  • 不说"永久免费""免费额度"——当前没有这项策略。
  • 不说"99.9% 可用性"——不给出无法兑现的承诺。
  • 不说"支持图片/语音/视频"——当前只开放文本模型。

这是一个聚合中转服务：模型本身的能力取决于上游，我们负责接入、计费与稳定性。把话说清楚，比说好听更有用。
