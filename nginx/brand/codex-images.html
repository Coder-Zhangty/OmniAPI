OmniAPI

在 Codex 对话中生成真实图片

保留 CC Switch 的现有主模型配置，额外接入 OmniAPI 图片 MCP 工具。模型为 gpt-image-2，当前已验收单张 1254×1254 PNG 文生图，品质可选 low（基础）、medium（标准）、high（精细），默认 low。实际开放状态与价格以模型广场为准。

下载图片 MCP 1.2.1 与完整教程

  1. 安装或确认 Python 3.10 及以上版本，将压缩包解压到 C:\OmniAPI-Images。脚本文件应位于此文件夹根目录。
  2. 在 CC Switch 的 MCP 页面新增 stdio 服务，启用到 Codex。配置如下，把令牌占位文字替换成您自己的 OmniAPI 令牌。
{
  "mcpServers": {
    "omniapi-images": {
      "command": "py",
      "args": ["-3", "C:/OmniAPI-Images/omni_images_mcp.py"],
      "env": {
        "OMNI_API_KEY": "替换为您自己的OmniAPI令牌",
        "OMNI_BASE_URL": "https://omniapi.biz/v1",
        "OMNI_IMAGE_OUTPUT_DIR": "C:/OmniAPI-Images/output"
      }
    }
  }
}

如果编辑器要求单个服务对象，填写内层 command、args、env；若分字段编辑，按对应字段填写。只添加 MCP，不要覆盖已有 Codex 提供商配置。请勿将 gpt-image-2 设为主对话模型。

  1. 完全退出并重新打开 Codex，确认有 omni_generate_image 工具。若可设置工具超时，设为 720 秒。在对话中发送：
请调用 omniapi-images 的 omni_generate_image 工具，生成一张白色背景、蓝色圆形图标的 PNG，文件名为 blue-circle.png。生成后告诉我文件路径，不要重复生成，也不用调用看图工具。

选择型号、尺寸与品质

新版工具支持按模型目录选择型号和规格。先调用 omni_list_image_models，再使用 omni_generate_image 的 model、size、quality 参数。具体组合与价格以实时目录为准。

已安装旧版工具，请下载新版后替换原 omni_images_mcp.py，再重启 Codex。原有 MCP 配置和已生成图片可以继续使用。

工具成功后会保存真实 PNG，并返回本地图片路径。默认每次一张，约人民币 0.35 元，按网站当前报价及您的账户规则结算。工具不会覆盖已有图片，也不会自动重复生成。

这是独立 MCP 图片工具接入；Codex 官方内置图片工具的支持条件可能不同。遇到超时请先核对调用记录，避免重复提交。将 Request ID 发到客服工作台即可继续排查。完整配置、Codex TOML 示例和常见问题均在下载包 README.md 中。
