## 一句话

OmniAPI 把多家主流大模型聚合成**一个接口**：一个 API Key、一个兼容 OpenAI 的地址，即可调用 Claude、GPT、Gemini、Grok、DeepSeek、GLM 等 **29 个模型**。

## 短版（约 90 字，适合群公告、简介栏）

OmniAPI 把 Claude、GPT、Gemini、Grok、DeepSeek、GLM 等 29 个模型聚合成一个接口：一个 Key、一个地址 `https://omniapi.biz/v1`，改一行代码即可接入，同时兼容 OpenAI 与 Claude 原生协议。按 token 公开计价，**1 元起充**，额度不每日重置、不自动续费，充值经人工核验到账。

### 接入成本几乎为零

- **OpenAI 兼容**：`/v1/chat/completions`，改 `base_url` 即可，原有代码不用重写。
- **Claude 原生协议**：`/v1/messages` 可直接用，不必再套一层转换。
- **Responses 协议**：`/v1/responses` 可用。

以上三种协议均已实测返回正常结果。主流客户端（ChatBox、Cherry Studio、NextChat、LobeChat 等）填上地址和 Key 即可使用。

```bash
curl https://omniapi.biz/v1/chat/completions \
  -H "Authorization: Bearer 你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-luna","messages":[{"role":"user","content":"你好"}]}'
```

### 计价：规则公开，没有隐藏项

- **每个模型的输入/输出单价都公开可查**，按 token 实际用量扣费，不做"按次收费"。
- 人民币按**公开行情折算**：下单时按最新报价换算额度，页面会显示本单使用的汇率、来源与报价时间，报价锁定 15 分钟。人民币中间价每个交易日公布一次，所以同一交易日内价格稳定；跨日可能随行情微调。
- **1 元起充**，没有"必须包月"或套餐外的最低消费。

### 额度是你自己的

- **不每日重置**：买到的额度不会到点清零。
- **手动续购，不自动续费**：不会在你不注意的时候扣款。
- 充值获得的额度长期有效；套餐额度有效期自开通时起算，到期未用完的处理在购买页写明。

### 充值：人工核验，不伪装自动扣款

1. 扫码付款（支持微信 / 支付宝）
2. 在充值页点一次「我已付款」，提交充值申请
3. 经营者在自己的收款渠道核对到账，**额度直接计入你的账户**
4. 刷新钱包页即可看到，不需要额外操作

每笔申请都有编号、金额与提交时间，充值前后余额可核对；同一笔付款只会入账一次。单笔最低 1 元。收款渠道到账可能有数分钟延迟。

### 拿得出手的工程底线

- 全站 **HTTPS**（TLS 1.2/1.3 + HSTS）
- **每日自动备份**数据库与配置
- 上线前完成真实上游验收：**19 项检查全部通过**，含计费准确性、流式计费、渠道隔离与端口隔离
- 管理员密码经哈希存储，管理入口独立鉴权

### 诚实的边界

- 当前开放的是 **29 个文本模型**；图片、语音类模型尚未开通。
- 它是一个**聚合中转**，模型能力本身取决于上游；我们负责接入、计费与稳定性。
- 没有"无限量""不限速"这类承诺 —— 额度按 token 真实扣除。
- 人民币汇率取自公开行情（东方财富 USD 货币对），由经营者决定采用；行情不可用时按经营者设定的备用汇率折算。**每单都会标明实际使用的汇率、来源与报价时间**，不会静默改价。

## 常见问题

**一个 Key 能切换所有模型吗？**
能。同一个令牌调用任意已开放模型，只改 `model` 字段。

**怎么计费？**
按 token 计费，输入与输出分别定价，单价公开。不按次数收费。

**额度会过期吗？**
充值额度长期有效；套餐额度按购买页写明的有效期计算。

**充值多久到账？**
经营者核对到账后即加额度，通常几分钟内；收款渠道本身可能有延迟。

**支持哪些客户端？**
任何支持自定义 OpenAI 兼容地址的客户端都可以，也可以直接用 SDK / curl。

**模型回答不好怎么办？**
换一个模型试试 —— 这也是聚合的价值：同一个 Key 里就有六家可选。
